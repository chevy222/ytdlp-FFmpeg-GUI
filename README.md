# ytdlp-FFmpeg-GUI（影栈）

**下载 · 转码 · 合并** 融为一体的 Windows 桌面视频工具箱 —— Rust + Tauri v2，绿色便携单 EXE，无安装包、不写注册表。

## 功能

- **统一列表即工作台**：URL 任务、本地文件、下载产物、转码/合并产物都在同一份列表里，下载 / 转码 / 合并是**作用于条目的动作**，没有分模块页面。行内提供下载 / 转码 / 剪辑 / 取消 / 重试 / 去登录 / 打开目录 / 日志 / 删除；勾选多条后出现批量操作栏（顺逆时针旋转 / 批量转码 / 合并… / 删除），工具栏右侧垃圾桶清空列表。
- **元数据先行**：条目先以"解析中"入列，解析完成才可操作。
  - URL 用 `yt-dlp -J` 解析标题、时长、封面、格式列表（清晰度/编码/大小/帧率/码率）；解析完成默认 **5 秒倒计时自动下载**，倒计时期间点"格式选择"即取消自动下载改手动。
  - 本地文件用 `ffprobe` + `volumedetect` 探测容器、分辨率、编码器、视频码率、帧率、音频编码、采样率、音频码率、音轨数、声道数、**最大音量**、时长、大小，以及 `extradata`（SPS/PPS）、主视频流/封面流索引、容器旋转标记；下载产物按同一标准再解析一遍，可直接进入转码/合并。
  - 画质/格式列展示 12 项源元数据：`容器 · 分辨率(4K/2K/xP) · 编码 · 视频码率 · 帧率 · 音频编码 · 采样率 · 音频码率 · 音轨数 · 最大音量 · 时长 · 大小`。
- **下载**：yt-dlp 驱动 1000+ 站点（B 站 / 抖音 / YouTube / X 等）；MP4 容器统一、不覆盖同名文件、并发分片与重试可配、仅音频提取（mp3）、播放列表展开平铺、时间范围下载；下载后自动后处理（画质上限 + 音量归一化 + 封面/元数据嵌入），再对产物做本地解析。Cookie 按站点 JSON 管理（`config/cookies/<host>.json`），缺失/过期时条目变"需要登录"，点"去登录"弹 **WebView2 内置登录窗**（顶部中心"登录完成"按钮，SPA 站点每 800ms 保活重建注入，走系统代理）。
- **转码**：批量转 **H.265**（自动 QSV → libx265 兜底，可强制 NVENC / AMF / libx265；硬编失败自动回退 libx265 重试一次）；支持**手动旋转**（列表封面缩略图上的顺/逆时针箭头，0°/90°/180°/270°，随条目保存）、分辨率上限（保比、不放大、偶数对齐）、码率封顶、音频增益（峰值 → 0dBFS，24dB 封顶，作用于全部音轨）、保留封面、碰撞安全命名（自动 `(1)`/`(2)` 递增或跳过）；输出 MP4 + `hvc1` + faststart。转码产物作为新条目回到列表。
- **合并**：勾选多条目 → 合并面板排序 → 参数一致（编码/分辨率/帧率/音频/采样率 + **extradata SPS/PPS**）零重编码直拼，不一致先统一转码再拼接；可选合并后音量归一化；产物回列表。
- **绿色便携**：所有产生文件都在 exe 同级（`config/` 配置与 Cookie/缓存、`temp/` 任务私有临时目录、`tools/` 工具链），固化内容以 JSON 存放并原子写；单实例运行（第二个实例把参数转发给已运行实例）。
- **站点分流代理**：站点白名单——只有勾选"走代理"的站点使用代理，其余一律直连；代理地址为空时全部直连。

## 快速上手

1. **下载**：粘贴视频链接 → 添加 → 自动解析（5 秒倒计时后自动下载，或点"格式选择"手动指定）。需要登录的站点会变"需要登录"，点"去登录"完成后自动重新解析。
2. **转码**：添加本地文件/目录（支持拖放）→ 解析完变"已就绪"→ 需要的话用封面上的旋转箭头纠正方向 → 勾选 → 批量转码（或行内"转码"）。参数统一在 设置-转码/通用 里配置。
3. **合并**：勾选多段素材 → 批量操作栏"合并…"→ 排序、选容器/编码器/文件名 → 确认输出。
4. **设置**：齿轮图标进入——依赖（四个工具路径 + 下载/更新/链接）、网络（代理地址 + 站点分流白名单）、Cookie（列出已保存站点，可删除）、下载（并发分片/重试/仅音频/播放列表/文件名模板/嵌入封面元数据）、转码（分辨率上限/码率封顶/默认编码器/QSV low_power/保留封面）、通用（默认输出目录/碰撞策略/音量归一化与增益上限/并发任务数）。依赖页每行"链接"可复制下载地址与构建页——下载慢时可手动下载，再把 exe 路径填进设置。底部状态栏左侧 `运行中 n/并发上限` 显示当前占用并发额度的条目数。

## 目录与数据存储（exe 同级）

```
config/     config.json（设置）· history.json（列表/队列/条目日志）· cookies/<host>.json（站点 Cookie）
            cache/thumbs/<条目id>.jpg（封面缩略图）
temp/       任务私有临时目录 temp/<任务id>/（导出的 Cookie 等）、temp/merge_<uuid>/（合并中间产物）、
            temp/tool_dl/（工具下载中间产物）
tools/      yt-dlp / ffmpeg / ffprobe / deno（托管模式工具链）· installed.json（安装指纹，供"更新"判断新版本）
logs/       运行日志 logs/app-<日期>.log（按天滚动、保留最近 7 天）
```

- 所有 JSON 均为**原子写**（临时文件 + rename；损坏则备份后回退默认）。
- GUI 程序没有控制台，`eprintln!` 看不到任何东西：配置/历史损坏、任务线程 panic、子进程清理失败等
  一律写进 `logs/app-<日期>.log`（排查问题先看这里）。
- 中间产物一律落在 `temp/`，不写进用户输出目录；任务结束/取消即清理本任务目录。
- 下载/转码/合并产物输出到默认输出目录（**默认桌面**，可配置）。
- 可执行文件解析顺序：设置里指定的路径 → exe 同级 `tools\` → 系统 PATH，**前一级取不到自动回退下一级**（首次运行 `tools\` 为空时，PATH 中已安装的工具照常可用）。
- 依赖页的「下载」固定装到 `tools\`，装完把路径写回设置（之后优先用这份）；「更新」只更新**当前生效的那一份**——设置里填的路径会就地覆盖、托管副本更新 `tools\` 里那份，当前用的是系统 PATH 里的则提示手动更新（不越界改你的安装）。更新前先查有没有新版本（yt-dlp / deno 比版本号，ffmpeg / ffprobe 优先比 gyan.dev release feed 的远端版本与本地版本，安装指纹仅作回退），已是最新会提示"无需更新"。下载中按钮显示"取消 <阶段> <百分比>"（连接 → 下载 → 校验 → 解压 → 安装）；底部状态栏实时显示各工具状态与版本（悬停可看解析到的路径）。

## 构建

**Windows 本地**（PowerShell 7）：

```powershell
pwsh ./scripts/build.ps1        # 核心层单测 → Clippy（核心层 + GUI crate）→ （可选）依赖审计 → release 构建
```

产物：`target/release/ytdlp-FFmpeg-GUI.exe`（workspace 根即仓库根，单 EXE）。

**CI**：push/PR 在 **Windows runner** 上跑两个 job——`lint`（核心层单测 → Clippy 核心层与 GUI crate，均 `-D warnings` → `cargo audit` 信息性不阻塞）通过后才进 `build`（release 构建、校验单 EXE、上传 artifact）；push `v*` tag 时走同一套门禁，额外打包 zip 并创建 GitHub Release 草稿。

**Linux 环境交叉编译 Windows 单 EXE**（cargo-xwin / zig，本地备用通道）：详见 `scripts/cross-build/README.md`。

## 命令行

```
ytdlp-FFmpeg-GUI --url <URL> [--url <URL> ...] [--cookies <path>] [--dir <path>]
                 [--yt-dlp-path <path>] [--deno-path <path>]
```

裸位置参数按 URL 处理；这些覆盖只对本次调用生效，不写入 config.json。应用未运行则启动执行，已运行则转发给现有实例。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Rust + Tauri v2（单窗口） |
| 前端 | 原生 HTML / CSS / JS（浅色 Soft UI + 磨砂玻璃），`ui/index.html`（结构+样式）+ `ui/app.js`（逻辑），无构建步骤 |
| 下载引擎 | yt-dlp（外部子进程，JSON 输出 + 进度行解析） |
| 处理引擎 | ffmpeg / ffprobe（转码 / 合并 / 探测 / 封面 / 音量） |
| JS 运行时 | deno（yt-dlp YouTube 组件必需，通过 `--js-runtimes deno:<路径>` 显式传入） |
| 内置登录 | WebView2 登录窗 + COM CookieManager 抓取含 HttpOnly 的 Cookie |
| CI | GitHub Actions（windows-latest） |
